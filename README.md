
# 💼 Portal Lowongan Kerja Berbasis Laravel

Aplikasi Portal Lowongan Kerja berbasis web yang dikembangkan menggunakan **Laravel 12** sebagai proyek akhir mata kuliah **Pemrograman Web**. Aplikasi ini memungkinkan administrator mengelola data perusahaan dan lowongan pekerjaan, sedangkan pengguna (pelamar) dapat melihat informasi lowongan yang tersedia.

---

## 📌 Fitur Utama

### 👨‍💼 Admin
- Login
- Dashboard
- CRUD Data Perusahaan
- Upload Logo Perusahaan
- CRUD Data Lowongan
- Pencarian (Search)
- Pagination
- Detail Lowongan

### 👤 Pelamar
- Registrasi
- Login
- Melihat daftar perusahaan
- Melihat daftar lowongan
- Melihat detail lowongan

---
